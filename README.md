# Minishell <img src="https://i.imgur.com/2mAvCN6.gif" width="50px">
<p>
  The objective of this project is for you to create a simple shell.
  This is a team project with @escastel (https://www.github.com/escastel)
  (https://github.com/escastel/Minishell)
</p>


## Key concepts:
<ul>
  In this project, we must comprehend and reproduce a basic Unix Shell, with similar behaviour to Bash.
IT must be able to parse and interpret commands, redirections, pipes, and more fundamentals system tools.
</ul>

## Programming concepts:

<li>Redirection and Pipelines</li>

<li>Environment Variables</li>
<li>Built-in Commands</li>
  </ul>
